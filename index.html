Why PIN strength matters

  • A 4-digit PIN has only 10,000 possible combinations. Attackers can try them all in seconds if no lockout is enforced.
  • A 6-digit PIN has 1,000,000 combinations — still small, but far harder to guess.
  • Avoid PINs based on birth years, repeating digits (1111), or sequential runs (1234, 123456).
  • Never reuse the same PIN across multiple services.
  • Data on common PINs is sourced from publicly disclosed credential breach research.
