# Car Logo Designer - Ferrari Edition 🏎️

A stunning car logo designer web application with Ferrari-inspired design. Create professional automotive logos with multiple styles and color schemes, optimized for iPad Pro and all devices.

## 🌟 Live Demo

Once deployed to GitHub Pages, access directly at:
- **Main URL**: `https://musahaseeb2012.github.io/webapp/` (auto-redirects to Car Logo Designer)
- **Direct Link (iPad Pro Optimized)**: `https://musahaseeb2012.github.io/webapp/car-logo-designer-standalone.html`

### 📱 iPad Pro Quick Access
The standalone version (`car-logo-designer-standalone.html`) is a single HTML file with everything embedded - perfect for iPad Pro! No external files needed.

## ✨ Features

### Car Logo Designer
- **4 Logo Styles**: Shield, Circle, Badge, and Minimal designs
- **4 Color Schemes**: Ferrari Red, Black & Gold, Silver & Chrome, Blue & White
- **Dynamic SVG Generation**: Create unique logos based on brand name and country
- **Gallery**: Save and reload up to 12 recent designs with localStorage
- **Download**: Export logos as SVG files
- **Copy to Clipboard**: Quick SVG code sharing
- **Randomize**: Instant inspiration with random combinations

### Design & Experience
- Ferrari-inspired theme with racing red (#DC0000) and yellow accents
- Racing stripe animation
- Glowing effects and premium aesthetics
- Fully responsive for all devices
- **iPad Pro Optimized**: Touch interactions, larger buttons, perfect layouts

## 🚀 Quick Start

### Option 1: Open Standalone Version (Recommended for iPad Pro)
Simply open `car-logo-designer-standalone.html` in any browser - completely self-contained!
- **No server needed**
- **No internet required** (after first download)
- **Works on any device**
- **Perfect for iPad Pro** - just upload to iCloud Drive or Dropbox and open!

### Option 2: Using Node.js Server
```bash
# Install dependencies
npm install

# Start server
npm start
# or
node server.js
```

Then visit: `http://localhost:3000/`

### Option 3: GitHub Pages (Share Online)
1. Enable GitHub Pages in repository settings
2. Set source to your branch (e.g., `claude/car-logo-designer-unusT`)
3. Share the link with anyone!
